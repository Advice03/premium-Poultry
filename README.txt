PREMIUM POULTRY WEBSITE
=======================

A responsive business website made with HTML, CSS and JavaScript in one index.html file.

OPEN IN VISUAL STUDIO CODE
1. Extract Premium-Poultry-Website.zip.
2. Open Visual Studio Code.
3. Choose File > Open Folder.
4. Select the Premium-Poultry-Website folder.
5. Open index.html.
6. Right-click and choose "Open with Live Server" (install the Live Server extension if prompted).
   You can also double-click index.html to open it in a browser.

FEATURES
- Home page
- Product catalogue with category filters and search
- Why Us section
- Testimonials
- Customer dashboard
- Add/remove product quantities in basket
- Order request form
- Recent order history stored in browser localStorage
- Responsive layout for desktop and mobile

IMPORTANT
- Product descriptions, prices, email and testimonials are sample content. Replace these with your real business details.
- Orders are saved only in the browser on the current device. This front-end demo does not email or send orders to a business automatically. A backend or form service is required for live order processing.
- Product photos and Google Fonts require an internet connection.
